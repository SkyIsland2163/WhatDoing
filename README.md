# 뭐하지 - 일정 관리 시스템

## 프로젝트 개요

"What_Doing?"은 개인과 팀의 일정 관리를 효율적으로 지원하기 위해 설계된 일정 관리 시스템입니다. 사용자가 직관적인 인터페이스를 통해 일정을 생성, 수정, 삭제하고, 일정을 공유할 수 있도록 설계되었습니다.

**참고: 본 문서는 프로젝트의 설계 내용을 나타내며, 실제 구현은 수행되지 않았습니다.**

## 프로젝트 목표

- 사용자 친화적인 일정 관리 환경 제공
- 학교, 복지관과 같이 공공기관의 일정 공유 지원
- 직관적인 캘린더 기반 인터페이스 구현

## 주요 기능

### 1. 일정 관리
- 일정 생성, 수정, 삭제

### 2. 캘린더 기능
- 월별/주별/일별 캘린더 뷰
- 일정 시각화
- 날짜별 일정 확인

### 3. 공유 및 협업
- 기관의 일정 공유
- 그룹(기관) 초대 기능

## 기술 스택 (설계 기준)

### Frontend
- HTML5
- CSS3
- JavaScript / TypeScript
- React 또는 Vue.js (선택 예정)

### Backend
- Node.js
- RESTful API

### Database
- MySQL


## 설계 문서

프로젝트 설계에는 다음 문서들이 포함되어 있습니다:

- `프로젝트 계획서.pdf` - 요구 사항 분석 및 설계 문서
- `What doing_ 일정 관리 시스템.pptx` - 프로젝트 프레젠테이션


## 참고 사항

본 프로젝트는 설계 단계의 문서로, 실제 시스템 구현은 수행되지 않았습니다. 제시된 모든 기능, 아키텍처, 기술 스택은 설계 단계에서 계획된 내용이며, 향후 구현 시 변경될 수 있습니다.
